P25 GPS Tracker — your radios' GPS, live on your offline map

The original Holy Grail, achieved: pull GPS straight out of your agency's BK P25 radios and plot each unit — by name — on your own offline ArcGIS Earth imagery. No cloud, no vendor subscription, no BK dongle. The tracker only ever reads the radio; it never reprograms anything.

One marker per unit, by name

The P25 unit ID is the key. Name it once (9076801 → Jax 24) and it sticks across sessions; an un-named unit shows its raw ID, so no dot is ever a mystery.

Built for the field

Live / Stale / Expired aging with an amber marker and age label, a pick-your-own retirement time (30 minutes to Never), keepalive and auto-reconnect, coordinate sanity, and a daily CSV track log.

Standard interoperability

The base radio relays each fix as standard NMEA over its USB network link; the tracker reads it and draws through ArcGIS Earth's local Automation API. Nothing is decrypted or reprogrammed.

The plotting tools

This repository is the plotting home of the family: read positions off a radio and draw them into ArcGIS Earth. The maps you plot on are built once with the companion TPKX production tools (QGIS → TPKX converter, Master 4 grid, ArcGIS Pro Batch Factory).

1

P25 GPS Tracker

Reads GPS from BK P25 radios over the base radio's USB link and plots each unit, by name, directly in ArcGIS Earth. Standard library only; no internet, no listening ports.

Garmin USB GPS Tracker

Reads a Garmin USB GPS (GPS 18 and kin) through Garmin's binary USB protocol — no COM port, no NMEA — and plots your own live position in ArcGIS Earth. Pure Python; nothing changed on the device.

Live tracking without surrendering the map scale

The tracker uses ArcGIS Earth's documented local Automation API. On each valid RMC update it reads the current camera, changes only X/Y to the current ME position, and preserves camera height and orientation. In live testing, the map recenters while the selected zoom stays put.

Live-tested ME center-screen tracking on ArcGIS Earth desktop.

Operator control: press T in the tracker console to toggle ME tracking. Stop the tracker process to suspend all live drawing updates.

Trifecta — ME + Raveon fleet + P25 on one map. A build of this tracker folds the P25 feed in as a third source so one script owns the ArcGIS Earth API. Download PRAVE / ME / P25 Tracker v3.0 (new bench build; passes its self-test and real-capture tests; full field test with live radios still pending).

Mobile offline deployment

Esri documents TPK/TPKX as supported local files in ArcGIS Earth Mobile. This project has additionally exercised a large local archive across several Android-class devices — the same maps you plot on.

Phone & tablet

District imagery can live locally instead of depending on a cellular data path at incident time.

Removable media

Project testing successfully opened TPKX from microSD and exFAT USB on an Android phone.

Picker caveat

On some Android paths, the in-app removable-storage picker can misbehave even when the same file opens from Android's file manager.

Important boundaries

The repository distributes plotting tools and documentation, not an imagery archive. The maps these tools plot on are produced separately; computers that build those maps need authorized access to the map source. Once produced and copied to field hardware, the TPKX files are local/offline content.
